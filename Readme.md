# Install Poetry in Windows
- first open power shell as administrator
- please type this command => (Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | py -
- if already install , please try this command => poetry --version 

# git clone via HTTPS
- please open visual studio code
- in terminal, please type command => https://github.com/fachri-pwr/poetry_test.git

# install poetry's project and run simulation 
- in terminal => poetry install
- after that, => poetry run python test.py
